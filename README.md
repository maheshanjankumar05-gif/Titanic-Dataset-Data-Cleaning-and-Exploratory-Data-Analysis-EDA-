# 🚢 Titanic Dataset - Data Cleaning & Exploratory Data Analysis (EDA)

A data analysis project focused on cleaning, preprocessing, and exploring the Titanic dataset to discover meaningful patterns, relationships, and insights through data visualization.

---

## 📖 Project Objective

The objectives of this project are to:

- Load and understand the Titanic dataset.
- Identify and handle missing values.
- Perform data cleaning and preprocessing.
- Analyze passenger information using descriptive statistics.
- Visualize relationships between different features.
- Draw meaningful insights from the dataset.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

---

## 📂 Dataset

**Dataset:** Titanic Dataset (`train.csv`)

The dataset contains passenger information such as:

- Passenger ID
- Survival Status
- Passenger Class
- Name
- Gender
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Ticket Number
- Fare
- Cabin
- Embarked Port

---

## 📊 Exploratory Data Analysis

The following analyses were performed:

- Dataset Overview
- Missing Value Analysis
- Data Cleaning
- Survival Count Analysis
- Passenger Class Distribution
- Gender Distribution
- Age Distribution
- Fare Distribution
- Survival by Gender
- Survival by Passenger Class
- Correlation Analysis

---

## 📈 Key Insights

- Female passengers had a higher survival rate than male passengers.
- Passengers in First Class had better survival chances.
- Most passengers were between 20 and 40 years old.
- Missing values in the Age column were replaced using the median.
- Missing values in the Embarked column were filled using the most frequent value.
- The Cabin column contained many missing values and was removed (if present).
